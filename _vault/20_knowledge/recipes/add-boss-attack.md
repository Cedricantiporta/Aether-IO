# Recipe: add or change a boss attack
1. Skills live in `engine/systems/bosses.ts` / `bosses2.ts` (cycle lists) with shared mechanics in `bossMech.ts`, projectiles/hazards in `bossFx.ts`.
2. Telegraph first: `spawnTelegraphCircle` / `spawnTelegraphLine` (enemies.ts), damage after the wind-up. Form 2 recolours telegraphs through `bossForms.ts`.
3. Close-range skills go through the proximity gate (`closeDue`, `proxBegin` in bossMech): they only fire when the hero, partner or a summon is near.
4. Invulnerable phases use the single owner `bp` (bossPhaseState); never start a second one; rate limit the INVULNERABLE label.
5. Hero CC: `knockHero` / `applyPlayerDebuff` / `slowHero` in combat.ts; keep the anti-chain rules (KNOCK_IMMUNE, no down while stunned/frozen/rooted, `resCC`). Bosses down the hero but are never downed.
6. No allocations per frame: pooled objects, module scratch vectors.
7. Test headless (HANDOFF "QA (headless)"): hero god mode near / far, count skill starts.
8. **I-frame ring pattern (dodge mechanics, `systems/dodgeMechs.ts`)**: a normal `pct` hit (never `crit`) so dash i-frames / ult negate it; telegraph = red `METEOR_SHADOW` floor + converging bright ring (`trick` event `DG_RING|conv|hex`) + a DASH! word + rising sound; a fast wave (80 u/s) that hits each hero when its front reaches the distance he had at release (so the dash window = the i-frame length, ~0.3 s, whatever the dash does); a double ring only if the hero holds 2 dash charges, no ring if the hero cannot dash (below the dash level, on ice, no charge back in time); no knockdown (get-up invulnerability swallows the second wave). Put new attack logic in a NEW file, own the boss with one `dodgeBoss` hook (state ATTACK + skip the AI), tick pools from `game.ts`. Enemy projectiles only hit with `damage > 0` even when `pct` is set.
8. Gorath / Elderroot have designed kits: `engine/systems/bossKitGorath.ts` / `bossKitTreant.ts` (shared strikes, statues, stun in `bossKit.ts`, fx in `render/BossKitFx.tsx`, 'trick' kinds `KIT_*`). Add a skill there (own real-second timers, `kitCircle` / `kitLane` for pct hits), not in bosses.ts / bosses2.ts; see HANDOFF 'Boss kits'.
